# తెలుగు పంచాంగం (Telugu Panchangam) — Android App

Drik Panchang మరియు Hindu Calendar యాప్‌ల నుండి ప్రేరణ పొందిన ఫీచర్లతో కూడిన
ఆండ్రాయిడ్ పంచాంగం/జ్యోతిష్య యాప్. పూర్తి Kotlin సోర్స్ కోడ్‌తో సిద్ధంగా ఉంది —
Android Studio లో ఓపెన్ చేసి నేరుగా బిల్డ్ చేసుకోవచ్చు.

## ఫీచర్లు (రెండు యాప్‌ల నుండి కలిపి)

- 🏠 హోమ్ స్క్రీన్ – రోజువారీ తిథి, పక్షం, నక్షత్రం, రాహుకాలం సారాంశం కార్డ్
- 📅 తెలుగు పంచాంగం – నెల మొత్తం తిథుల ప్రివ్యూ (CalendarMonthActivity)
- 📜 రోజువారీ పంచాంగం – తిథి, నక్షత్రం, యోగం, కరణం, సూర్యోదయ/అస్తమయం,
  రాహుకాలం, యమగండం, గుళికకాలం — మునుపటి/తర్వాతి రోజుకు నావిగేషన్‌తో
- 🎉 భారతీయ ఉత్సవములు – ప్రధాన పండుగల జాబితా
- 🕉️ రోజువారీ ముహూర్తం – పగలు/రాత్రి చౌఘడియలు, అభిజిత్ ముహూర్తం
- 🔯 కుండలి / జ్యోతిష్యం – జననం తేదీ/సమయం/స్థలం ఆధారంగా లగ్నం, నవగ్రహ
  స్థానాలు (అన్ని 9 గ్రహాలు, రాశి+డిగ్రీలతో), జన్మ నక్షత్రం/పాదం, మరియు
  వింశోత్తరి మహాదశ టైమ్‌లైన్ — అన్నీ Swiss Ephemeris ఖచ్చితత్వంతో
- 🍩 వేదిక్ రాశిఫలాలు – 12 రాశులకు రాశిఫలం
- 🪔 భక్తి సాహిత్యం – ఆరతి, చాలీసా, స్తోత్రాల జాబితా (placeholder)
- 🛕 వ్రత సేకరణ – ఏకాదశి, సంకష్టి, ప్రదోష మొదలైనవి
- ➕ తిథి జోడించండి – వ్యక్తిగత తిథులను (పుట్టినరోజు మొదలైనవి) సేవ్ చేసుకోవచ్చు
- ⚙️ సెట్టింగులు – పంచాంగ గణనకు అక్షాంశం/రేఖాంశం మార్చుకోవచ్చు
- 🔱 **షోడశ వర్గ చక్రాలు** – రాశి (D1), భావ చక్రం, నవాంశ (D9) తో సహా మొత్తం
  16 శాస్త్రీయ వర్గ చార్టులు (D1,D2,D3,D4,D7,D9,D10,D12,D16,D20,D24,D27,
  D30,D40,D45,D60) — డ్రాప్‌డౌన్ స్పిన్నర్‌లో ఎంచుకుని లగ్నం + 9 గ్రహాలు ఏ
  రాశి/భావంలో ఉన్నాయో చూపిస్తుంది (`ShodashaVargaActivity`)
- ℹ️ పంచాంగం గురించి – పంచాంగ మూలకాల వివరణ

## గణన లాజిక్ (PanchangCalculator.kt) — ఇప్పుడు Swiss Ephemeris ఆధారితం

ఖచ్చితత్వం కోసం ఈ యాప్ **Swiss Ephemeris** (Astrodienst వారి ప్రామాణిక
ఖగోళశాస్త్ర లైబ్రరీ, Thomas Mack గారి pure-Java పోర్ట్) ను ఉపయోగిస్తుంది:

- **లైబ్రరీ:** `com.github.krishnact:swisseph:master-SNAPSHOT` (JitPack ద్వారా)
  — pure Java, ఇది Android లో ఏ native/JNI ఆధారపడకుండా నేరుగా పనిచేస్తుంది.
- **మోడల్:** అంతర్గత Moshier సెమీ-అనలిటికల్ మోడల్ (`SEFLG_MOSEPH`) —
  గ్రహాలకు ~1 ఆర్క్-సెకను, చంద్రుడికి కొన్ని ఆర్క్-సెకన్ల ఖచ్చితత్వం. దీనికి
  ఎలాంటి బాహ్య `.se1` ఎఫెమెరిస్ డేటా ఫైళ్లు అవసరం లేదు — పూర్తిగా ఆఫ్‌లైన్‌లో పనిచేస్తుంది.
- **అయనాంశ:** లాహిరి (Chitrapaksha) — భారతీయ పంచాంగాలలో ప్రామాణికమైనది
  (`swe_set_sid_mode(SE_SIDM_LAHIRI, ...)`), అన్ని రేఖాంశాలు నేరుగా
  నిరయన (సైడీరియల్) గా వస్తాయి (`SEFLG_SIDEREAL`).
- **తిథి, నక్షత్రం, యోగం, కరణం** — సూర్య/చంద్ర సైడీరియల్ రేఖాంశాల భేదం/మొత్తం
  నుండి (ఇప్పుడు Swiss Ephemeris ఖచ్చితత్వంతో).
- **సూర్యోదయం/అస్తమయం** — `swe_rise_trans()` ఉపయోగించి (వాతావరణ వక్రీభవనం
  (refraction), సూర్య బింబ వ్యాసార్థం, భౌగోళిక స్థానం అన్నీ పరిగణించి కచ్చితంగా).
- **లగ్నం (Ascendant)** — `swe_houses()` (Placidus 'P' అక్షాంశ వ్యవస్థ,
  సైడీరియల్ ఫ్లాగ్‌తో).
- **నవగ్రహాలు** — సూర్య, చంద్ర, కుజ, బుధ, గురు, శుక్ర, శని, రాహు (Mean Node),
  కేతు (రాహు + 180°) — అన్నీ `KundaliActivity` లో చూపబడతాయి.
- **వింశోత్తరి దశ** — చంద్రుడి జన్మ నక్షత్రం/పాదం ఆధారంగా ప్రామాణిక 120-సంవత్సరాల
  వింశోత్తరి చక్రం (9 మహాదశలు, ప్రారంభ దశ యొక్క మిగిలిన బ్యాలెన్స్‌తో సహా).
- **రాహుకాలం, యమగండం, గుళికకాలం** — ఖచ్చితమైన సూర్యోదయ/అస్తమయాల మధ్య పగటిని
  8 భాగాలుగా విభజించి, వారాన్ని బట్టి ప్రామాణిక భాగం ఎంపిక చేయబడుతుంది.

### ముఖ్యమైన సెటప్ గమనిక

`com.github.krishnact:swisseph` అనేది **JitPack** నుండి వస్తుంది గనుక, మొదటిసారి
Gradle sync చేసేటప్పుడు ఇంటర్నెట్ కనెక్షన్ అవసరం (జార్ ను జిట్‌ప్యాక్ బిల్డ్
చేసి అందించడానికి కొన్ని క్షణాలు పట్టవచ్చు). `settings.gradle` లో ఇప్పటికే
`https://jitpack.io` రిపోజిటరీ జోడించబడింది.

### సమస్య పరిష్కారం (Troubleshooting)

- `import de.thmac.swisseph.*` దొరకలేదని ఎర్రర్ వస్తే: Android Studio లో
  Gradle sync చేసేటప్పుడు ఇంటర్నెట్ ఉందని నిర్ధారించుకోండి (జిట్‌ప్యాక్
  మొదటిసారి రిపో బిల్డ్ చేయడానికి కొన్ని నిమిషాలు పట్టొచ్చు). లైబ్రరీ
  ప్యాకేజీ పేరు మారితే (repo నిర్వహణలో మార్పుల వల్ల), అసలు సోర్స్‌ను
  https://github.com/krishnact/swisseph లో చూసి import స్టేట్‌మెంట్లను
  అప్‌డేట్ చేయండి — ప్రస్తుతం అది `de.thmac.swisseph` ప్యాకేజీలో ఉంది.

> ఇంకా ఎక్కువ ఖచ్చితత్వం కావాలంటే (NASA JPL డేటా స్థాయి), Astrodienst వారి
> అసలు `.se1` ఎఫెమెరిస్ ఫైళ్లను డౌన్‌లోడ్ చేసి `assets/ephe/` లో పెట్టి
> `SwissEph(path)` కన్‌స్ట్రక్టర్‌కు ఆ పాత్ ఇవ్వొచ్చు, మరియు ఫ్లాగ్‌లను
> `SEFLG_MOSEPH` బదులు `SEFLG_SWIEPH` గా మార్చవచ్చు. కానీ Moshier మోడల్ ఇప్పటికే
> పంచాంగం/జాతక అవసరాలకు సరిపడా ఖచ్చితమైనది.

## APK ఎలా పొందాలి

ఈ ప్రాజెక్ట్‌ను నేను నేరుగా బైనరీ APK గా కంపైల్ చేయలేను — నేను పనిచేసే
సాండ్‌బాక్స్‌లో Android SDK లేదు, Google/JitPack సర్వర్లకు నెట్‌వర్క్ యాక్సెస్
కూడా బ్లాక్ చేయబడింది. మీకు రెండు సులభమైన మార్గాలు:

### మార్గం 1: Android Studio (2 నిమిషాలు, మీ కంప్యూటర్‌లో)
1. ఈ ఫోల్డర్‌ను Android Studio లో "Open" చేయండి, Gradle sync పూర్తయ్యే వరకు వేచి ఉండండి.
2. మెనూ: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. బిల్డ్ పూర్తయ్యాక కింద కనిపించే "locate" లింక్ నొక్కితే
   `app/build/outputs/apk/debug/app-debug.apk` కనిపిస్తుంది — దీన్ని ఫోన్‌కు
   పంపి ఇన్‌స్టాల్ చేసుకోవచ్చు (Settings లో "Install from unknown sources" ఆన్ చేయాలి).

### మార్గం 2: GitHub Actions (మీ కంప్యూటర్‌లో ఏమీ ఇన్‌స్టాల్ చేయాల్సిన అవసరం లేదు)
ఈ ప్రాజెక్ట్‌లో `.github/workflows/build-apk.yml` ఇప్పటికే జోడించాను:
1. ఈ కోడ్‌ను మీ సొంత GitHub రిపోజిటరీకి పుష్ చేయండి.
2. రిపో లో **Actions** ట్యాబ్‌కు వెళ్లండి — "Build Debug APK" వర్క్‌ఫ్లో
   ఆటోమేటిక్‌గా రన్ అవుతుంది (లేదా "Run workflow" నొక్కి మాన్యువల్‌గా ప్రారంభించండి).
3. రన్ పూర్తయ్యాక, ఆ రన్ పేజీలో కింద **Artifacts** విభాగంలో
   "TeluguPanchangam-debug-apk" అనే జిప్ డౌన్‌లోడ్ చేసుకోండి — అందులో
   ఇన్‌స్టాల్ చేసుకోగల `.apk` ఫైల్ ఉంటుంది. (GitHub సర్వర్లకు Android SDK,
   JitPack రెండూ యాక్సెస్ ఉంటాయి కాబట్టి బిల్డ్ సమస్య లేకుండా పూర్తవుతుంది.)

> గమనిక: ఇది "debug" APK — పరీక్షించడానికి సరిపోతుంది. Play Store లో పెట్టాలంటే
> `assembleRelease` + సైనింగ్ కీ అవసరం (Android Studio లో Build → Generate
> Signed Bundle/APK ద్వారా సులభంగా చేయొచ్చు).

## ఎలా బిల్డ్ చేయాలి (సోర్స్ నుండి)

1. ఈ ఫోల్డర్‌ను (`PanchangApp/`) Android Studio (Hedgehog+) లో "Open" చేయండి.
2. Gradle sync పూర్తయ్యే వరకు వేచి ఉండండి (అవసరమైన SDK/Kotlin ప్లగిన్‌లను
   ఆటోమేటిక్‌గా డౌన్‌లోడ్ చేస్తుంది).
3. లాంచర్ ఐకాన్‌ను మెరుగుపరచాలంటే: `File → New → Image Asset` ఉపయోగించండి
   (ప్రస్తుతం ఒక సాధారణ placeholder వెక్టర్ ఐకాన్ ఉంది).
4. `Run ▶` నొక్కి ఎమ్యులేటర్ లేదా ఫోన్‌లో ఇన్‌స్టాల్ చేయండి.

## తదుపరి మెరుగుదలలు (సూచనలు)

- GPS ఆధారంగా స్థానాన్ని ఆటోమేటిక్‌గా గుర్తించడం (`FusedLocationProviderClient`)
- జాతక సరిపోలిక (అష్టకూట) కోసం రెండు వ్యక్తుల నక్షత్రాలను పోల్చే స్క్రీన్
  (ఇప్పుడు navagrahaLongitudes() ఇప్పటికే అందుబాటులో ఉంది కాబట్టి ఇది సులభం)
- అంతర్దశ (Antardasha) / ప్రత్యంతర్దశ స్థాయి వరకు వింశోత్తరి దశను విస్తరించడం
- పండుగల డేటాను REST API నుండి డైనమిక్‌గా లోడ్ చేయడం
- నోటిఫికేషన్స్ (ఏకాదశి/పండుగ రిమైండర్లు) కోసం WorkManager
- అత్యధిక ఖచ్చితత్వం కావాలంటే అసలు Swiss Ephemeris `.se1` డేటా ఫైళ్లను
  `assets/` లో చేర్చి `SEFLG_SWIEPH` వాడటం (పైన సెటప్ గమనిక చూడండి)
